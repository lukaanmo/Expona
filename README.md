# Expona · 储蓄计划

Expona 是一款本地优先的个人储蓄规划应用，支持人民币多账户管理、收入确认、动态资金分配、储蓄目标与操作记录。提供网页原型和 Windows 免安装桌面版。

这是一个使用 AI 辅助开发的个人早期项目。目前采用可解释的规则规划算法，不是机器学习，也不预测投资收益。

## 开发环境

使用 Node.js 24 和 npm。在项目目录运行 `npm ci` 安装开发与桌面打包依赖。网页本身不依赖外部服务。

## 启动

在此目录运行 `npm start`，打开 http://127.0.0.1:4173 。不要直接双击 HTML，应用使用 JavaScript 模块。

运行 `npm test` 验证金额守恒、优先分配、核对缺口、账户转账和月末日期。

## 使用

1. 设置账户余额、已有储蓄、生活预算和到账日；也可先体验模拟数据。
2. 在计划设置中补充备用金和自由支配预留目标，在首页添加储蓄目标和固定支出。
3. 已到账收入需要手动确认，模板不会自动记账。分配建议也需单独确认。
4. 每周核对所有账户余额，先补录遗漏收入。转账同时更新两边账户。
5. 余额不足时先扣自由支配，剩余缺口需手动调整资金用途。消费不会自动扣减储蓄或备用金。

## 边界

数据使用当前浏览器当前来源的 localStorage，无账户、同步或备份。请固定使用相同浏览器与地址。清理浏览器数据后无法恢复。

固定支出仅作为循环预算，不自动扣款；支付后通过余额核对和手动用途调整反映。目标日期展示剩余月均需求，不保证按期完成。未来增长储备不预测收益。

服务器仅监听本机回环地址；手机布局已实现，但当前地址不能直接从另一台手机访问。尚未发布上线。

代码：`dist/engine.js` 为金额计算，`dist/app.js` 为交互，`dist/style.css` 为响应式样式。


## 动态策略与记录（V2）

“分配策略”可切换优先级补足与期限进度＋剩余加权。动态模式按日历月计算期限需求（包含本月），先执行必要预留，再按目标优先级安排期限额度，最后将剩余资金按倒数优先级权重分配；增长储备的权重可配置。目标上限生效后，多余资金继续流转。月份基于设备本地日期，不存在后台自动转账或定时执行。

备用金月度上限扣除本月已分配额度；手动取出资金不会恢复已用额度。百分比规则在底层按本次未分配资金池计算，当前界面不开放其编辑。规则引擎支持 fill、period、percent、remainder，权重尾差按余数大小和规则 ID 确定性处理。

所有保存操作使用浏览器 Web Locks 和版本检查，过期预览需要重新打开。同一操作 ID 不可重复提交；相同名称、日期、账户、金额的收入会提示重复，确为两笔时可在收入名称中增加区分。流水从升级后开始，包含变更前后快照；当前不提供自动撤销，纠正通过手动调整并留下新记录。流水与余额在同一 localStorage 文档中保存，存储失败不会更新界面中的状态。

算法是确定性的规则规划，不是机器学习，不联网、不上传财务数据，也不预测收益。浏览器中已验证配置表单和只读试算；完整保存流程依赖 Web Locks，需新版 Chrome/Edge。12 项自动化测试覆盖核心计算与记录版本控制。

## Windows 桌面版

发布后的 exe 可从本仓库的 Releases 页面下载。

免安装文件输出到 `release/Expona-0.2.0-Windows-x64.exe`。双击运行，不需要启动网页服务器或安装 Node.js。应用仅加载随包附带的页面，不请求网络 API。

桌面版数据存储于当前 Windows 用户的 `%APPDATA%/Expona`（以 Electron 实际 userData 路径为准），与浏览器存储独立，不自动迁移网页记录。移动 exe 不会移动用户数据。未购买代码签名证书，此构建未签名。

开发：`npm run desktop`；打包：`npm run build:exe`。打包需要下载 Electron 和 NSIS 工具，目标是 Windows x64。
